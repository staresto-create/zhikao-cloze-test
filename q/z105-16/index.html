105 年指考 克漏字 第16題

字彙選義線索：句內答對率 33%
答對率 33%：當年每 100 位考生，有 33 位答對。

He was also the man who cracked the 16 uncrackable Enigma code used by Nazi Germany.

  1. (A)eventually
  2. (B)precisely
  3. (C)concernedly
  4. (D)supposedly

答案：(D)　supposedly

題目編號：Z105_16（已自動幫你填到回報表單裡）🚩 回報這題有問題

解析

supposedly 意為「據稱、一般認為」，帶有「後來證實並非如此」的暗示：他破解了那套「據稱無法破解」的恩尼格瑪密碼；eventually（最終）、precisely（精確地）、concernedly（關切地）語意都不合。

深入解析

你可能會這樣想

supposedly 這個副詞課本少見，而且它的作用很微妙——它不是在陳述事實，而是在標示「別人是這麼說的，但未必是真的」。

本句的趣味就在這裡

the supposedly uncrackable Enigma code ＝「那套據稱無法破解的密碼」。既然圖靈把它破解了，uncrackable（無法破解）顯然只是「大家以為」而已——supposedly 就是用來標記這個落差。少了它，句子會變成「他破解了無法破解的密碼」，自相矛盾。

怎麼判斷

看到形容詞前面要填副詞、而那個形容詞又與句子的事實衝突時，就要想到這類「據稱」的字：supposedly、allegedly（據稱，多用於指控）、reportedly（據報導）、seemingly（看似）。

常考字詞與句型

supposedly + 形容詞（據稱…的）、allegedly（據稱，多用於指控）、reportedly（據報導）、be supposed to（應該）、crack a code（破解密碼）。
