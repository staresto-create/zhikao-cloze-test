95年指考 克漏字 第19題

連接詞／轉承語線索：跨句答對率 56%鑑別度 51

If you've ever seen the Sean Connery movie Medicine Man, __18__ the annual convention of wizards and witches will be familiar to you. 19 , get prepared for the overwhelming attack of wizards and witches here.

  1. (A)If any
  2. (B)If not
  3. (C)If ever
  4. (D)If only

答案：(B)　If not

題目編號：Z95_19（已自動幫你填到回報表單裡）🚩 回報這題有問題

解析

承接前句「如果你看過那部電影，這個巫師大會你會覺得很熟悉」，這句是條件對比的另一半：「如果沒看過，就做好心理準備」，If not（如果沒有）呼應前面的 If you've ever seen。If any／If ever／If only 都不符合這種「前後條件對比」的邏輯。

深入解析

你可能會這樣想

四個選項都是 If 加一個短短的字，形態一模一樣，你會憑中文挑一個。

怎麼判斷

線索一定要跨句才看得到。前一句是 If you've ever seen the Sean Connery movie Medicine Man, then...（如果你看過那部電影，那麼……就會很熟悉）。空格這一句要講的是相反的那一半：那如果沒看過呢？英文不必把整個條件再說一次，用 If not 就好——它等於 If you haven't seen it，not 把前面那個條件整個否定掉。填進去讀成 If not, get prepared for the overwhelming attack of wizards and witches here（如果沒看過，那就準備好迎接這裡巫師與女巫的猛烈攻勢）。這是英文常見的省略：重複的部分不必再說一次。國中學過的簡答就是同一件事——Do you like it?—Yes, I do.（do 代替 like it）、Are you coming?—I'm afraid not.（not 代替 I'm not coming）。看到 If not、if any、if ever 這幾個短形，先問一句「它在代替前面哪一段」。

干擾選項

If any（如果有的話）用來限定數量，常接在名詞後面（Correct the mistakes, if any.）；If ever（如果真有的話）用來加強「幾乎不曾」（He seldom, if ever, complains.）；If only（要是……就好了）表示與事實相反的願望，後面通常配假設語氣。三個都是 If 加一個字的短形，形態吻合，容易被順手選走。

常考字詞與句型

if not（如果不是的話，代替前面否定掉的條件）、if any（如果有的話）、if ever（如果真有的話）、if only（要是……就好了）、I'm afraid not.（恐怕不行，not 代替整個否定句）、get prepared for（做好準備迎接）。
