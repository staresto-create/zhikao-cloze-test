91年指考 克漏字 第30題

字彙選義線索：句內答對率 52%
答對率 52%：當年每 100 位考生，有 52 位答對。

It is an easy arithmetic 30.

  1. (A)question
  2. (B)feedback
  3. (C)product
  4. (D)industry

答案：(A)　question

題目編號：Z91_30（已自動幫你填到回報表單裡）🚩 回報這題有問題

解析

arithmetic question（算術問題）為固定搭配，指前述50元及300元的價差問題其實是簡單的算術題；feedback／product／industry 均不符合 arithmetic 的搭配語意。

深入解析

你可能會這樣想

前一句才剛出現過 feedback，眼睛還停在那個字上，很容易順手把它填進來。答對率五成二。

怎麼判斷

空格前面是 arithmetic（算術的），要問的是「算術的什麼」。an arithmetic question（一道算術題）是常考的字詞搭配，同義的說法還有 an arithmetic problem。四個選項裡只有 question 與 arithmetic 搭得起來，同句就選得出答案。下一句可以再驗算一次：街上 NT$50 就買得到的 CD，為什麼要花 NT$300 以上買同一張？這正是一道算術題。鑑別度高達 54，分開的是兩種讀法：把 It 讀成單純回指前一句的人，順手選了剛出現過的 feedback；看出這一句是在替下一句那道價差算式起頭的人，選了 question。

干擾選項

feedback（回饋）：前一句才出現過，但「一個簡單的算術回饋」講不通，它與 arithmetic 搭不起來。product（產品）：唱片是產品沒錯，但在數學裡 product 指的是「乘積」，與這裡要說的「一道題目」是兩回事。industry（產業）：與 arithmetic 完全無關。

常考字詞與句型

an arithmetic question（一道算術題）、an arithmetic problem（一道算術題，同義說法）、solve a problem（解決問題）、spend ＋ 金錢 ＋ on（把錢花在……上）、the same one（同一個）、feedback（回饋，不可數名詞）。
