95年指考 克漏字 第18題

連接詞／轉承語線索：句內答對率 60%鑑別度 60

If you've ever seen the Sean Connery movie Medicine Man, 18 the annual convention of wizards and witches will be familiar to you.

  1. (A)since
  2. (B)so
  3. (C)then
  4. (D)though

答案：(C)　then

題目編號：Z95_18（已自動幫你填到回報表單裡）🚩 回報這題有問題

解析

If...then... 是固定的條件句型，then 承接 If 子句，引出「那麼……就會……」的結果。since（因為/自從）、so（所以，通常不與 if 連用）、though（雖然）都不符合這種標準條件句結構。

深入解析

你可能會這樣想

中文說「如果……那麼就……」，你會直覺想找一個「就」，而 so 的中文正是「所以」，很容易先被選走。

怎麼判斷

鑑別度高達 60，分開的是知不知道 if 子句後面該用哪一個字呼應。逗號前面已經有一個從屬連接詞 If 帶著子句，逗號後面是主要子句。英文不允許在同一組主從結構裡再放一個對等連接詞來連，所以 so 出局；since 與 though 都是從屬連接詞，放進去會變成兩個從屬子句、整句沒有主要子句，也不成立。剩下 then——它是副詞、不是連接詞，正好可以擺在主要子句前面呼應前面的 If，中文就是「那麼」。填進去讀成 If you've ever seen the movie Medicine Man, then the annual convention will be familiar to you。國中學過的「一個句子裡不能同時用 Although 和 but」是同一件事：中文的「雖然……但是……」「如果……所以……」到了英文只能留一邊。

干擾選項

so 是對等連接詞，中文的「所以」讓它看起來剛好，但它不能與句首的 If 並用；since（既然、自從）與 though（雖然）都是從屬連接詞，會讓整句缺少主要子句。

常考字詞與句型

If ..., then ...（如果……那麼……）、Although ＋ 子句（雖然，主要子句不再加 but）、so（所以，對等連接詞）、though（雖然）、be familiar to somebody（為某人所熟悉）、convention（大會、集會）。
